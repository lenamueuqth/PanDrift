# PanDrift

A simple PanDrift Manager for Automated workflow management.

PanDrift is built to be simple and practical, focusing on doing one thing well.

**Why PanDrift?**

- A simple PanDrift Manager for Automated workflow management

## Key Features

- A simple PanDrift Manager for Automated workflow management

## Technology Stack

- rust
- rust framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PanDrift.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

PanDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
